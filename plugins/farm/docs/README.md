# Maplewood Farm

A tutorial zone teaching how to build. Most rooms have something broken in them:
the `hint` command says what to change, and in which file. Change it, type
`apply`, and carry on.

This plugin is meant to be edited, which is unusual: normally a plugin stays
untouched and you override it from your own worldlets. To start your own world
instead, remove it with `bin/plugin remove farm`, and override `start_location`
on `!menu/new/character!` so that new characters appear somewhere else.
