!farm/room/gate!
parent = "farm/generic_room"
title = "The Farm Gate"
locked = True
description = Description("""
Two weathered fence posts stand on either side of the path, joined
by a sturdy gate of oak planks gone silver with age. A low stone
wall stretches away into the hedgerows on both sides, its mossy
stones warm to the touch. The smell of crushed nettles rises from
the verge where boots have trodden the weeds flat.

$gate_state.
""")
hint = """
    The gate is locked. Open plugins/farm/worldlets/room.txt, find farm/room/gate,
    and change 'locked = True' to 'locked = False'. Then type APPLY.
"""
exits = [
    Exit("north", !farm/room/road!),
    Exit("south", !farm/room/yard!),
]

def can_leave(self, character, exit):
    if exit.name == "south" and self.locked:
        character.msg("The gate is locked. Try the HINT command.")
        return False
    endif

    return True

def describe_gate_state(viewer: Entity):
    if self.locked:
        return """
            The gate won't budge. The old iron latch is rusted shut, and the wood
            groans when you push against it
        """
    else:
        return """
            The gate stands open, its iron latch lifted. A worn path leads
            south into the farmyard
        """
    endif

!farm/room/hallway!
parent = "farm/generic_room"
title = "The Hallway"
repaired_steps = 3
bedroom_private = True
description = Description("""
A narrow hallway runs through the heart of the farmhouse. The
whitewashed walls are bare but for a row of iron coat hooks,
one still holding a waxed canvas jacket stiff with age. The
floorboards creak and give slightly underfoot, and the air
smells faintly of beeswax and damp wool. A draught slips in
from somewhere, stirring the dust in thin ribbons of light that
fall through a high window.

To the west, a plain wooden door leads to the farmer's bedroom.
$bedroom_door_state.

At the far end, a wooden staircase climbs toward the loft.
$staircase_state.
""")
hint = "The staircase needs at least 5 repaired steps. Change 'repaired_steps = 3' to 'repaired_steps = 5' (or higher) in plugins/farm/worldlets/room.txt and APPLY. The bedroom door to the west is blocked out of propriety -- you can remove that restriction by changing 'bedroom_private = True' to 'bedroom_private = False' if you're curious."
exits = [
    Exit("south", !farm/room/kitchen!),
    Exit("up", !farm/room/loft!),
    Exit("west", !farm/room/bedroom!),
]

def can_leave(self, character, exit):
    if exit.name == "up" and self.repaired_steps < 5:
        character.msg("Even jumping wouldn't be enough, too many broken steps.")
        return False
    endif

    if exit.name == "west" and self.bedroom_private:
        return False
    endif

    return True

def describe_staircase_state(viewer: Entity):
    if self.repaired_steps >= 5:
        return f"The staircase looks solid -- {self.repaired_steps} steps repaired and steady underfoot"
    else:
        return f"Only {self.repaired_steps} steps have been repaired so far. The rest are splintered or missing -- not enough to climb safely"
    endif

def describe_bedroom_door_state(viewer: Entity):
    if self.bedroom_private:
        return "It wouldn't be proper to go in uninvited"
    else:
        return "It stands slightly ajar, the room beyond quiet and dim"
    endif

!farm/room/loft!
parent = "farm/generic_room"
title = "The Loft"
lever_pulled = True
gears_oiled = True
description = Description("""
The loft is dim and close, the slanted ceiling low enough to
brush your hair. Old hay bales are stacked against the far wall,
their sweet, dusty smell filling the warm air. Cobwebs hang in
pale curtains from the rafters, swaying in a draught you can
feel but not find. Thin blades of light cut through cracks in
the roof tiles, catching the slow drift of dust motes.

In one corner, a child's narrow cot is tucked against the wall,
its thin mattress covered with a patchwork blanket. A cloth doll
with button eyes sits propped on the pillow, and at the foot of
the bed a small wooden horse lies on its side, one leg chipped.
A few flat stones are stacked on a stool nearby -- a half-built
tower, abandoned mid-game.

Near a heavy wooden trapdoor in the floor, a brass lever juts
upright, connected to the door by a system of gears and pulleys.
A small brass plaque reads: "Pull lever and oil gears to open."

$mechanism_state.
""")
hint = """
    Both conditions are met (lever pulled, gears oiled), but the trapdoor won't open.
    Read the can_leave method in plugins/farm/worldlets/room.txt carefully
    -- there's a small word that inverts the logic.
"""
exits = [
    Exit("down", !farm/room/hallway!),
    Exit("east", !farm/room/barn!),
]

def can_leave(self, exit):
    if exit.name == "east":
        character.msg("Hum, it seems the lever won't budge for some reason.")
        return self.lever_pulled and not self.gears_oiled
    endif

    return True

def describe_mechanism_state(viewer: Entity):
    if self.lever_pulled and self.gears_oiled:
        return """
            The lever has been pulled and the gears are oiled -- every condition
            met. Yet the trapdoor holds firm. Something in the mechanism's
            logic must be wrong
        """
    elif self.lever_pulled:
        return "The lever has been pulled, but the gears are still dry. The trapdoor remains sealed"
    elif self.gears_oiled:
        return "The gears are oiled, but the lever has not been pulled. The trapdoor remains sealed"
    else:
        return "The lever has not been pulled and the gears are dry. The trapdoor remains sealed"
    endif

parent = "farm/generic_room"
title = "The Barn"
description = Description("""
The old barn is tall and hollow, thick oak beams rising to a
roof that creaks in the wind. Stalls line one side, their gates
hanging open, the straw inside scattered thin and dry. The air
is heavy with the smell of old hay, leather tack and the faint
sourness of long-absent livestock. Bales and grain sacks fill
the far side in crooked towers, some split and spilling.

A few swallows dart between the high rafters, their calls sharp
and quick in the echoing space. Near the south doors, a heavy
iron chain is looped around a fence post.

The large barn doors stand wide open to the south, letting in
$light.

A wide path beyond leads out toward open fields.
""")
hint = """
    The description uses $light for dynamic text, which calls the describe_light method.
    Right now it always returns 'darkness'. Fix it to check the time
    with gametime.now(!calendar/farm!) and its time_of_day property -- return
    something like 'warm morning light' during the day, and 'darkness'
    only at night.
    If you're stuck, head over to https://pytelix.org/farm.html

    Bramble the dog is chained here too: in plugins/farm/worldlets/npc.txt,
    change 'freed = False' to 'freed = True' on farm/npc/bramble.
    Then APPLY.
"""
exits = [
    Exit("west", !farm/room/loft!),
    Exit("south", !farm/room/fields!),
]

def describe_light(viewer: Entity):
    return "darkness"

def can_leave(self, character, exit):
    if exit.name == "south":
        light = self.describe_light(None)

        if light == "darkness":
            character.msg("You hit an invisible wall. Well, not fun!")
            return False
        endif
    endif

    return True
